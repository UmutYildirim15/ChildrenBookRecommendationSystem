# ChildrenBookRecommendationSystem
Due to the excessive amount of information on the internet, personal discovery becomes important. On social media, streaming, and shopping platforms, recommendation systems are now essential tools for guiding users toward content that best suits their interests. To make predictions about preferences and increase engagement, these systems study item attributes and user behavior. Collaborative filtering has grown more popular by being able to recognize patterns of user-item interaction. Deep learning has come along, and these algorithms can now detect complex, non-linear patterns with much better-quality suggestions.
This study aims to create a complex book recommendation system using the Children's Books dataset from Goodreads. Non-interactions in this data cannot be interpreted as disinterest, only positive interactions (like ratings) are observed. The data contains implicit feedback, which makes this a major challenge. The study frames the prediction as a binary classification problem and generates training data using negative sampling to get around this. Despite the sparsity and implicit nature of the dataset, the primary objective is to provide accurate, customized suggestions.
First, the project will deploy a Neuralized Matrix Factorization (NeuMF) baseline model by combining General Matrix Factorization (GMF) and Multi-Layer Perceptron (MLP) to leverage both linear and non-linear information. Secondly, to reduce data sparsity and enhance model generalizability, the research leverages pre-trained embeddings and transfer learning. Third, it examines the use of attention mechanisms to enable the model to closely focus its attention on the most important latent features, leading to more accurate predictions. Lastly, it attempts to combine both transfer learning and attention in one model to determine their combined influence on recommendation quality.
